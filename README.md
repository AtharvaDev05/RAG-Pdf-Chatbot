# RAG PDF Chatbot

A Retrieval-Augmented Generation (RAG) PDF Chatbot built from scratch using modern AI technologies.

## 🚀 Features (Planned)

- Upload one or more PDFs
- Semantic search using vector embeddings
- Retrieval-Augmented Generation (RAG)
- Source citations
- Multi-turn conversation memory
- Hybrid search
- Modern React frontend
- FastAPI backend
- FAISS vector database
- Gemini integration

## 🛠 Tech Stack

- Python
- FastAPI
- React
- Tailwind CSS
- FAISS
- Sentence Transformers
- LangChain (where appropriate)
- Google Gemini

---

> This project is being built step-by-step from scratch to understand every component of a production-style RAG pipeline.
